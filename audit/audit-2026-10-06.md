### Build Logs — Critical Failures

Latest build log `build-20261005-2306.log` (2026-10-05 23:14 UTC) ended with **4 fatal
package errors** that aborted the ISO build:

```
E: Package 'libasound2' has no installation candidate
E: Package 'ntfsprogs' has no installation candidate
E: Unable to locate package sfdisk
E: Unable to locate package ddrescue
```

Root cause — all four are Ubuntu 24.04 (Noble) naming mismatches:

| Old / Wrong Name | Correct Ubuntu 24.04 Name | Notes |
|-----------------|---------------------------|-------|
| `libasound2` | `libasound2t64` | Renamed for 64-bit time_t transition |
| `ntfsprogs` | `ntfs-3g` | Merged into ntfs-3g package |
| `sfdisk` | `util-linux` | `sfdisk` ships inside `util-linux`, already installed |
| `ddrescue` | `gddrescue` | GNU ddrescue binary is in `gddrescue` on Debian/Ubuntu |

Additional warning: `W: --force-yes is deprecated` — benign but should be updated
to `--allow-unauthenticated` or `--allow-change-held-packages` as appropriate.
